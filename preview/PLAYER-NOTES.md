# 多段逐幀播放器

`app.js` 讀取 `animation/catalog.json` 的 `clips`，每個 clip 使用自己的版本、SHA-256、格數、播放順序和每格時長。有圖才播放，缺失或載入失敗的情境會顯示待補／重試，不代用其他動作。

## 目前日常介面（20260927-experience2）

主頁現有 11 套可選造型、15 個播放變體，讀取 `experience/themes.json` 和主 catalog。這是把待審素材接入開發試玩，並非使用者已批准所有畫稿；13 組原始候選仍在獨立 `?review=candidates` 頁，原來源、完整格數與審稿鍵保留。以下後半部的「只有哈欠」「六組候選」數字是先前階段的驗證紀錄。

- 主頁「照顧／衣櫥／陪伴／日記」是可操作的本機功能。明選衣服優先於情境；只有「跟著情境」會為投餵換廚師、為生活情境換裝。明選衣服缺少某動作時，只記錄照顧、短句與可選聲音，不偷偷換裝冒充同衣服動作。
- 飽足與熟悉度都是遊戲數值（0–100）：一口 +12 飽足／+2 熟悉，摸摸 +1 熟悉，飽足每小時緩慢減 1.5。投餵保留原本 3 秒間隔。心情由使用者自己選；沒有感測或健康推論。日記保留最近 60 則，可下載。
- 新資料存於 `patrick.experience.v1`，既有 `patrick.pet.v1`、播放器設定、事件和審稿不刪除。新計時器支援專心／運動陪伴／呼吸、10–7200 秒、暫停／繼續／結束；截止時刻用真實時間，取消不算完成，同一計時只記一次完成。舊 pet 計時可遷移，背景到期只更新結果，不補演聲光慶祝。
- 自訂睡前／早上時間只影響「跟著時間」。新預設 22:00–06:00，已有舊 pet 時段則沿用；起訖相同代表不自動睡前。生日接受月日（含 02-29），一般節日沿用已核實日曆。生日與節日按本機日期每天一次；安靜／背景時記為已看過，恢復後不補演。節日日期預演不改真實時計或計時。
- 連摸三下、找驚喜、前景整點、生日／節日均有各自冷卻。只有有圖的動作播放；泡泡、星點等為另層道具，不搖動整張角色。減少動態、背景、腕下或省電會停止特效與音效。正常「演一下」不會偷偷進入審稿；逐格審稿仍暫停待機。
- 聲音預設關閉，按使用者操作後才可播放本地 WAV；不疊播，安靜或背景時停聲。輕震只在瀏覽器支援時呼叫，尚未驗證真機。12／24 小時與日期顯示由獨立 boot 數字時鐘負責。
- 「原味手臂時計 · 試稿」讀取有 SHA 驗證的 PNG 和三層輪廓資料，以共用肚子軸心及每隻手的來源角度計算真實時間；互動時隱藏手臂時計，演完回到當前時間。缺圖時保留數字與一般角色。這套手臂接合仍待美術修正：目前 00:00 手尖會碰嘴下緣，06:30 形態亦待審，不能當成完成稿。
- 大預覽與腕上尺寸共用 frame canvas／固定每段 scale。衣櫥卡片也沿用實際舞台比例，不能因 common canvas 留白而把不同衣服縮成不同角色大小。

## 畫格與尺寸

- 主畫布與小畫布同為 832 × 992，按 416 : 496 顯示；小畫布可見寬度固定 200 CSS px。
- 有 `frameRegions` 時先驗證 sidecar SHA-256，以及其來源 PNG 的路徑、SHA、尺寸。`frames[].rows` 是原圖座標的逐列像素遮罩；播放器依整數 `translation` 將整張原圖畫進遮罩，保留原 alpha，再得到整段共用尺寸的 N × N 畫布。`placement` 只是來源框左上在共同畫布的位置，必須等於 `sourceBounds.xy + translation`，不可拿來平移整張 atlas。
- 三種畫面（大預覽、200 px 腕上視窗、每格縮圖）共用同一份提取後畫布。每幀完整頭腳由輪廓分組決定，不能只裁 `sourceBounds`，也不能把鄰幀落在框內的像素一起畫入。輪廓資料載入或校驗失敗會停用該段，絕不悄悄退回錯切的等格模式。
- 沒有 sidecar 的舊格式才使用整個 cell，容許 443.5 px 這類固定小數格寬。`frameIndices` 在兩種格式都可指定來源格順序或重複，例如雙眨。
- `destinationRect()` 每段只計算一個縮放與定位。提取後使用 `canvas.anchorPixels / canvas.width` 的實際腳底位置對齊 `catalog.master.anchorNormalized`；舊格式使用 `clip.anchorNormalized`。`clip.scale` 整段共用，絕不根據每格內容邊界另行縮放。當前 metadata 使用 `N / 原最大格邊長` 作整段 scale，保留原來源像素的顯示倍率；共同画布變大不會讓角色突然縮小。
- 基本角色方框為 x = 0.1W、y = 0.25H、邊長 = 0.8W。安全區上緣為 0.24H，底線為 0.93H；素材作者仍須核對調整後的可見像素是否在安全區內。
- 數字時鐘由獨立 `boot.js` 更新。圖片或模組錯誤不停止讀時；重試保留本機資料。

## 何時播放

- 自動待機：前景等 10–22 秒後選一組可用 idle，避免連續使用同一 ID。只有一組時不連續重播。每段結束後重新等待。
- 睡前哈欠：切入睡前時一次；冷卻 10 分鐘，本機保存。頁面初次載入不重演進入事件。手動「播放一次」可隨時審稿，不修改自動事件冷卻。
- 「偶爾眨眼」只控制待機；不禁止手動互動或切入睡前的一次性事件。
- 摸摸頭／投餵優先於正在播放的 idle，不排隊。投餵沿用 pet-core 的 3 秒間隔。
- 減少動態、背景、腕下、低電量停止自動播放；恢復時重新等候，不追補。靜態條件下手動播放改為逐格前進。
- 選稿、選格、調速、暫停與寫意見會保留看稿狀態，直到按「繼續日常陪伴」或切換生活情境。
- 生活日期只影響節日查詢；計時和冷卻用真實時間。專心計時保存截止時刻，返回時顯示剩餘／完成狀態，不補演離線時已結束的慶祝。

## 意見與保存

每個 clip 分「動作」與「造型」兩個意見區，各有逐格評語及整段文字。新儲存鍵使用完整 clip ID、version、SHA-256；相同版本號換圖也不會套用舊意見。舊版相同 hash 意見可讀入「動作」區，原 storage 保留。匯出為 `schemaVersion: 2` 的多 clip JSON。

輪廓提取是取圖方式修正，原 PNG、clip ID、版本及意見鍵保持不變。匯出另含 `currentRendering`（當前提取版號、regionsHash、共同畫布）與 `savedReviewRendering`；舊記錄沒寫過取圖方式時保持 `unknown`，不把原先針對等格裁切的意見改成修正後的新批准。若舊記錄有 `rendering` 欄位，按原內容保留。

播放器設定、睡前事件、pet 狀態分開保存。若本機儲存不可用，仍可在當次頁面匯出意見；跨重新載入的計時／冷卻則無法保證持續。

## 待修候選模式

只有精確的 `?review=candidates` 會讀 `animation/candidates.json`；其他 query 值仍讀主 catalog，不能以網址傳入任意檔案。頁首顯示「待修動畫審稿｜非正式播放素材」，每組直接展示 description 的已知問題。

此模式共用逐格播放器，只允許手動播放一次、選格、調速及審稿。待機和生活狀態輪詢不建立；互動、情境及陪伴設定停用。程式另在寫入入口阻止主 settings／events／pet key 更新。候選意見使用獨立 `patrick.animation-candidate-review.<id>.v<version>.<sha256>`，不讀取主預覽或 legacy 意見；匯出標明 `reviewMode: candidates`、候選 catalog、各段品質狀態及已知問題。

候選分類讀 `reviewGroup: idle | interaction | scene`；「本批新增」讀目錄內最新 `batch`，未標分類的舊稿歸生活情境。筆數與格數跟隨目錄，不固定在第一批的 5 組／64 格。篩選會保留仍符合分類的目前稿與幀；空分類保留目前畫面並明示沒有畫稿。意見鍵不改，匯出永遠包含完整候選清單。待機分類只供手動看稿，並不啟用日常自動眨眼；新素材也不自動加入主 catalog。

新增 `test-candidates-browser.cjs` 專項 3/3 通過：5 組真實候選共 64 格可手動查看，200 px 同步、固定來源格／目的矩形、零自動播放和主狀態写入、hash 命名空間隔離及匯出均通過。測試只驗播放器和資料流程，`artQualityApproved: false`；安全區觀察僅記錄，不作為候選畫稿已合格的結論。報告與截圖在 `output/playwright/candidate-review/`。另重跑主哈欠實圖與 legacy 審稿 2/2，輸出在 `output/playwright/candidate-main-regression/`；先前完整 9/9 報告保留。
