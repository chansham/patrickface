# 派大星角色方向與逐件確認

更新：2026-09-27。本文件保存使用者本輪回饋與後續製作要求；具體素材提案未經逐件確認前，不標成已批准成品。

## 主畫面的讀時與角色安排（2026-09-27新增確認）

使用者重新提供Spinnaker派大星手臂指針參考，確認希望把這個機制帶進主畫面：**中央是派大星，兩隻手臂兼作時／分針並能演出動畫；上方保留清楚的大型電子數字時間，電子時間是主要讀時方式。**

- 電子時間負責一眼看清現在幾點；中央角色負責陪伴、個性與手臂時計的趣味。不能因參考是實體指針錶，就移除或縮小上方電子時間。
- 手臂平時指向當前時／分；互動時可暫時離開指針姿態，演出結束後回到**當時**的正確時間。表演期間上方數字仍正常更新，不隨角色傾斜、縮放、遮擋或停止。
- 可加少量簡潔刻度，或只出現「12」／「6」，作為構圖和方向提示。這是可選方案，並未要求完整數字圈或指定必須同時保留12與6。
- 構圖先保留上方讀時區，再安排角色、手臂最大動作範圍、服裝和道具；日期、情境小字與刻度維持次要層級。
- 這次確認的是布局與互動機制；2D、3D、服裝、表情和具體美術仍依展示效果逐件選擇，沒有指定唯一畫風。先前對星星睡衣的喜好和三張v1的不喜歡仍各自保留。

此方向應同時作為網頁與原生Watch下一步對齊的依據。原生目前已有上方數字與共軸雙臂；本輪只讀核對，未修改Swift或宣稱通過Apple SDK編譯。源碼現況與待對齊處見[專案狀態](PROJECT-STATUS.md#本輪主畫面方向與原生只讀核對)。

## 已確認的使用者方向

- 最新回饋：部分造型太中規中矩。使用者匯出的標記明確否定正裝、下班、街頭3張v1，沒有逐張文字理由；其他款未標記，不解讀成已選中。希望先跑通動態、彩蛋和互動。畫風仍由實際效果挑選，沒有统一3D。
- 本輪設計提案：用「一本正經卻拿反東西」「疲倦到癱軟」「耍帥卻差點失衡」建立可讀笑點。这些具體點子是製作方提案，尚待使用者看圖；生成服務本輪未產生重畫圖。

- 使用者喜歡上一批3張圖，尤其是睡衣與星星帽子的方向。這是對已看到範例的正向回饋，**不代表整個style-library、所有新變體或最終產品畫風已被批准**。
- 希望有更多眼鏡、帽子、正裝與嚴肅表情；角色要有多種個性，不能每次都只賣萌。
- 希望有幾套不同睡衣，並加入泡澡情境。
- 使用者詢問Watch能否偵測泡澡；這是待查證的能力問題，不是已接受以感測器推測私生活的功能設計。

這些方向延伸目前的腕上寵物，不將產品鎖定成單一2D／3D畫風、單套睡衣或只展示錶面的形式。具體畫風和素材仍按實際展示逐件確認。

## 下一批候選：衣服、配件、表情分開設計

下表是可製作的候選，不是使用者已選定的全部清單。

| 類別 | 候選內容 | 要看見的差異 |
|---|---|---|
| 眼鏡 | 圓框、方框、細框、墨鏡 | 看書的專心、正式的認真、淡定的酷；不要只換鏡框而臉完全相同 |
| 帽子 | 喜歡的星星睡帽優先延伸；另提案貝雷帽、日常帽、毛線帽 | 帽型與姿態一起改變個性，仍能看清派大星輪廓與眼睛 |
| 正裝 | 西裝領帶、襯衫背心、簡潔正式外套 | 嚴肅注視、思考、整理領帶、一本正經；保留角色特色，不強制加腮紅或愛心 |
| 睡衣A：星星 | 延續已喜歡的星星元素與睡帽，先保持核心辨識 | 這是優先延伸方向，不擅自大改成另一套設計 |
| 睡衣B：條紋 | 條紋上下裝、可選素色睡帽 | 清爽、睏倦、剛起床；和星星款能一眼區分 |
| 睡衣C：格紋 | 格紋睡褲／成套睡衣、可選眼鏡 | 安靜看書或若有所思，睡衣不必配睡著表情 |
| 睡衣D：素色 | 深藍、奶油色等候選色，少量包邊 | 以剪裁和姿勢作差異，避免全靠印花 |
| 泡澡 | 浴缸、毛巾、泡泡、小鴨；可換成不同浴缸與背景 | 放鬆閉眼、淡定發呆、一本正經泡澡都成立；不只一種甜笑 |

表情至少涵蓋：平靜、認真／嚴肅、思考、困惑、無奈、得意、睏倦、開心。表情來自使用者選擇或角色演出；不是對使用者真實情緒或健康的判定。不要把所有表情都處理成大眼甜笑，也不要讓「嚴肅」只是把嘴移除而沒有眉眼、姿勢差異。

衣服、頭飾、眼鏡、表情與場景應盡量可組合。製作時保留圖層／錨點與遮擋規則；睡帽不能切掉眼睛，眼鏡不能讓眨眼消失，袖口不能破壞手臂的時計轉軸。真正接到既有手臂時計或寵物App前，仍須檢查小尺寸可讀性與動作，而非只看大張概念圖。

## 泡澡場景與觸發的決定

泡澡首先是**角色在本機演出**：使用者按一下進入，再按一下結束；即使手錶保持乾燥也可看。UI可叫「泡澡場景」，在沒有可靠來源時不顯示「偵測到你在泡澡」。

可逐步研究的入口：手動、使用者指定時間、配對iPhone碰浴室NFC標籤；若已經有相容智慧家庭設備，再評估場景按鈕或感測器的可選提示。後三者尚不代表已接入；Home自動化到本App的通道也需要另驗。

Water Lock只負責防誤觸和排水。部分Watch可取得入水、深度及水溫資料，仍不能單憑這些辨識泡澡；機型、權限、capability與session都要確認。Apple也要求避免肥皂／肥皂水和蒸氣室。具體型號與溫度界線、官方來源見[能力地圖的泡澡查證](CAPABILITY-MAP.md#apple-watch能否知道正在泡澡)。

場景素材、手動選擇與設定預設在本機處理；不需要拍攝、錄音或辨識浴室影像，不預設保存／上傳泡澡時刻。若以後需要跨裝置同步或回顧紀錄，須另定義必要資料、保留時間與可關閉方式。這是本輪的產品方向，尚未宣稱程式已實作。

## 素材確認方式

每次展示清楚標示素材名稱、服裝／配件／表情與版本，保留使用者看到的那個版本。素材狀態分為「候選」「使用者明確喜歡／選中」「待修改」「可製作成App素材」，不能把對其中一張的稱讚批次套用到整個資料夾。

下一批要讓人能直接比較眼鏡、帽子、正裝、幾套睡衣與泡澡，並讓嚴肅和安靜表情佔有實際份量。先確認角色與每件服裝，再做透明素材、動畫和原生整合；概念圖好看不等於已完成可換裝圖層或可動骨架。

本文件未新增任何已批准素材、未更改原生程式；目前功能與安裝狀態分別見[能力地圖](CAPABILITY-MAP.md)與[安裝說明](INSTALLATION.md)。
