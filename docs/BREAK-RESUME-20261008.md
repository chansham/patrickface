# 保存活動、休息與返回

更新：2026-10-08。本輪交付 App／網頁的實際按鈕流程，沒有新增 Siri 捷徑或原畫。

## 使用方式

在網頁「陪伴」、iPhone「陪伴計時」或 Watch 選單的「陪伴計時」中，先開始一段活動，再選 1／3／5 分鐘並按「保存進度，休息一下」。

- 保存原活動的 ID、種類、剩餘時間，以及原先正在執行或已暫停的狀態。只有休息倒數在計時，原活動凍結。
- 休息結束、App 進入背景或重新開啟，都不會自動接回原活動。
- 按「返回原活動」才恢復。原本正在執行的活動從保存的剩餘時間繼續；原本已暫停的活動仍維持暫停。
- 可以提早返回或取消休息。取消休息仍保存原活動；「放棄原活動」另有明確確認，放棄不算完成，也不會停止仍在執行的休息倒數。
- 重複休息或返回不會重設截止時間、重複日記或獎勵。已到期的活動先按原規則完成結算。
- 有保存中的活動時，開始其他活動會保留它並說明如何返回或放棄。不支援巢狀休息；沒有任務文字、工作內容或多個並行活動。

休息與返回不更改使用者選擇的睡眠情境、服装、聲音或心情。它是陪伴倒數，不寫入 HealthKit 健身／正念紀錄，也不切換系統 Focus。

## 保存與同步

原生 `PatrickExperienceState` 新增可選 `breakSession`，其中包含凍結的 `savedActivity`、`resumeOnReturn` 和 `breakActivityID`。舊 v1 存檔缺少此欄位仍可讀取。完整狀態沿原有 WatchConnectivity 合併規則傳遞；兩端都應升級到含此功能的版本，尚未驗證舊版 App 對未知欄位的來回傳遞。

網頁以原有 `patrick.experience.v1` 本機存檔保存同一流程，不與原生設備同步，也不讀寫候選審稿存檔。日記匯出包含目前保存的活動。

iPhone 的 Live Activity 使用不可變快照與有順序的更新工作；快速休息／返回，以及重設資料後，不讓過期的更新覆蓋最新狀態。這項系統呈現仍須真機驗證。
