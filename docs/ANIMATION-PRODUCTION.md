## 圖集與 catalog 契約

`tools/validate_animation_catalog.py` 是只讀驗證器，讀 catalog 和 PNG，輸出診斷到終端；不寫圖、不裁圖、不重排格、不更新 SHA，不自動批准美術。

| 欄位／規則 | 要求 |
|---|---|
| 頂層 `master` | `id`、`anchorNormalized`、固定 `scale`、`cellAspect`；可提供 `displayRectNormalized`。所有 clip 對應同一角色／鏡頭基準。 |
| 每個 clip 身分 | 唯一 `id`、`title`、`category`、`status`、`triggerKinds`；狀態不等同使用者最終批准。 |
| 檔案 | `atlas` 為專案相對路徑；`sha256` 對應實際 PNG bytes；`width`、`height` 對應解碼尺寸。 |
| 來源格 | `columns`、`rows` 定義整張圖的規則網格。每格來源寬 `width/columns`、高 `height/rows`，全段共用，允許分數尺寸。 |
| 播放序列 | `frameCount` 是播放幀數；`durationsMs` 必須同長度且全部大於零。可提供等長 `frameIndices`，每個值是由零起算的來源格索引，可重複。 |
| 雙眨例子 | 4×2 圖集可保留 8 個來源格，`frameIndices` 連續引用兩次形成 16 播放幀，並設定 16 個停留時間；不要求 `frameCount === columns*rows`。 |
| 固定對位 | clip 可明示一個共用 `scale`／`anchorNormalized`，並繼承或指定匹配的 `masterId`。不可逐幀按透明 bbox 自動縮放、裁切或移動來掩蓋飄移。 |
| 跨 clip | 對照同一 master 的頭身比例、鏡頭和落點。站姿可以比坐姿高，道具可擴大 bbox，不能強迫所有 clip 可見高度一致。 |
| 未產出 | `plannedClips` 的未落盤 ID，以及 `planned`／`generation-blocked`／`revision-blocked` 等無 atlas 項目，明記未交付，不計為可播放成果。 |

現有 1774×887 的 4×2 圖集每格為 443.5×443.5。網頁應使用固定分數 source rect；若原生輸出整數像素圖，需對整個 clip 使用明訂的一致轉換流程，不能每格自行裁到人物邊界。驗證器的整數 inspection rect 只供檢查 alpha，不是播放器來源框。

診斷分級：

- **Error**：缺檔、SHA 不符、尺寸不符、索引越界、播放時間無效、引用空白格、錯誤 master 或逐幀自動 fit；不能當資料契約通過。
- **Warning**：分數格、alpha 碰格界、可能鄰格滲入／被裁、可見大小大幅變化、跨 clip 比例差異、尚未產圖。姿態改變本來就可能改變 bbox，必須人工看原因，不能自動判定醜或自動修齊。
- **美術驗收未評估**：即使零 error／warning，仍需看眼部顏色、輪廓彩邊、接合、體積、動作因果、服裝一致、小尺寸及首尾。數字通過不等於美術通過。

執行方式：

```text
python -B -X utf8 tools/validate_animation_catalog.py
python -B -X utf8 tools/validate_animation_catalog.py --json
python -B -X utf8 tools/test_animation_catalog.py
```

預設結束碼 1 表示資料錯誤；只有 warning 仍為 0，但結果顯示 `TECHNICAL_PASS_WITH_WARNINGS` 且 `artApproval: not-assessed`。可用 `--strict-warnings` 令 warning 回傳 2；這是人工檢查門檻，不是將幾何警告當作審美定論。

## 原生素材同步

`tools/sync_animation_bundle.py` 先驗證 catalog；資料錯誤會停止，警告仍保留供檢查。來源只允許專案 `animation/`，目的只允許 Watch 的 `PatrickFace/Animation/` 與手機的 `iOSCompanion/PatrickCompanion/Animation/`，用 `--target watch|iphone|all` 選擇（預設 Watch），拒絕路徑穿越與符號連結／junction 重導向。它不裁切、縮放或重新編碼 PNG。

```text
python -B -X utf8 tools/sync_animation_bundle.py
python -B -X utf8 tools/sync_animation_bundle.py --check
```

預設執行實際複製，每份暫存及目的檔均核對 SHA。先放圖集，再更新原樣複製的 catalog；保留 `animation/` 前綴，由原生 loader 去除。`managed-assets.json` 記錄來源、目的、SHA、大小、可用／待補 clip 與管理狀態。

`--check` 不建立目錄、不写檔，只檢查是否同步最新；過期回傳結束碼 1。相同內容不重寫；需要覆蓋時只接受本工具已記錄且本地 bytes 未被修改的檔案。未知同名不同內容或已管理檔案被手動修改會停止；其他未知檔案及已退役的舊 managed 檔案都不會自動刪除。沒有 atlas 的待補項目保留為待補，不能藉同步增加可用數。

這只完成原生資源放置與位元組一致性，不代表 Xcode 編譯、簽名、上錶或美術驗收。同步安全回歸在臨時目錄通過六項；本機無權限建立符號連結，相關實體連結案例明記跳過，不能說該環境案例已實測通過。

## 每批交付的門檻

1. 先提供實際圖片／圖集與精確版本，將生成失敗和未產出保留原狀態。
2. catalog 資料與來源格檢查通過；所有 warning 有人工檢視結果，不用逐幀自動縮放掩蓋尺寸問題。
3. 正常速度、大圖、约 200 CSS px 小圖、逐幀、靜音都可看；記錄實際看到的問題，不只寫程式測試 PASS。
4. 排程能處理優先級、冷卻、暫停、離開及返回；手動審稿不被搶走；舊事件不補播。
5. 逐版本取得使用者回饋。方向接受、單段接受、整套完成分開記錄；未標記不推定喜歡。
6. 原生接入、Apple SDK 編譯、簽名分發與真機驗收各自報結果；瀏覽器可播不等於已可戴上手錶。
