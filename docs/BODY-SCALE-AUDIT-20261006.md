# 角色本體尺度盤點 · 2026-10-06

這份檢查量角色內部的可見基準，不拿圖集格子、透明畫布或含帽子／道具的總外框當作角色大小。它沒有修改 PNG，也沒有逐格拉伸或自動把差異消掉。

## 可信度與覆蓋

- 去重後 15 張來源、172 張原畫；主目錄與候選共有 29 種編排。三種眨眼節奏只計一張來源。
- 120 格有可用的臉部量測代理，52 格因閉眼、遮擋或追蹤不可靠保留未量測；不能稱全部 172 格本體尺寸已確認一致。
- 臉横截／眼下緣間距各有 120 格數值，眼線至足底僅 100 格。太空充電、廚師的共用 anchor 落在坐墊底，浴缸遮住腳，所以這三組足底指標全部為 `null`，沒有拿道具底代替人的腳。
- 六組中性首格（哈欠、派對、太空服、正裝、廚師、啞鈴）的來源眼框及臉部尺線已由 root 與瀏覽器 QA 獨立實看；其餘逐格結果仍是可重查的自動追蹤代理，並非逐格人工解剖標註或美術批准。
- 正裝第 8–11 格手遮住眼／臉，明確排除；第 9 格曾得到半張臉的錯誤小值，已移除，不當作角色真的縮半。

## 尺規定義

1. **眼下緣線的可見臉部橫截寬**：先找兩眼可見白色區域下緣中點，沿這條斜線量眼橋附近同一片粉色臉部皮膚的左右邊。排除帽子、衣服、橙色啞鈴、透明留白及獨立粉色物件；不稱整個頭顱寬。細黑外框與採樣約有 2 個來源像素的不確定度。
2. **兩眼下緣中點距離**：可補查臉部尺度，但不是瞳孔距；瞇眼、眼形和轉頭都可能改變它，不獨自決定倍率。
3. **眼線至足底的垂直距離**：僅作坐姿／軀幹縱向代理，不能跨不同姿勢硬壓成相同身高；不能確認真正足底時不量。衣服、枕頭或手遮住的軀幹寬一律不推算。

眼白搜尋可用原輪廓作搜尋範圍；最終尺規不以該外框尺寸作為量測值。影格內臉寬／眼距偏離參考超 8%、縱向代理超 10%，以及跨造型參照差超 15%，都標警告而非自動校正。量測與原畫／姿勢差異必須分辨，所有 `artApproval` 均為 false。

## 來源像素到畫面像素

以播放器實際公式與 SHA 為準：每個來源像素映到 `665.6 × clip.scale ÷ 共用畫布寬 N` 個 832×992 舞台像素。再乘當前版式倍率：經典 1、一眼大字 0.69、角色劇場 0.95、運動資訊 0.56。200 CSS px 寬預覽另乘 `200/832`；此數字不是手錶物理毫米。

報告逐格保存 source、stage、四版式和 200 px 換算，並分 `sourceAll` 與 `actualUsed` 的最小／最大／平均及異常影格。候選實際只用經典版式；其餘三種值標為比較推算。停播的原畫仍計入 `sourceAll`，例如正裝原第 13／15／16 格可量到的眼線至足底比首格短約 12–13.5%；第 14 格閉眼留未量測，不用主播放避開它來抹掉原畫問題。

## 本次有限倍率校準

以既有使用者接受方向的哈欠中性首格作參照（臉橫截 182.72、眼下緣間距 64.31 個舞台像素），不要求不同衣服／姿勢具備相同外形。只對兩段整組改倍率，所有原畫與相對幀大小保留。

| 尺規，832 舞台 px | 派對原先 → 1.30 倍 | 太空服原先 → 1.10 倍 |
|---|---:|---:|
| 臉部橫截 | 157.30 → 204.49 | 152.56 → 167.81 |
| 兩眼下緣間距 | 45.07 → 58.59 | 46.46 → 51.10 |
| 與參照的臉寬絕對偏差 | 13.9% → 11.9% | 16.5% → 8.2% |
| 與參照的眼距絕對偏差 | 29.9% → 8.9% | 27.8% → 20.5% |

兩項獨立臉部代理都較接近參照；派對仍短身、太空服眼距仍偏小，沒有宣稱本體已統一。廚師的高帽／小臉、正裝的短軀幹、被摸與運動造型較大的臉都保留待審，不能只用一個總高度或倍率解决。

派對長哨在運動版式會向右伸，整體 UI 已把資訊欄共用左界移至 476；校準後原圖強輪廓最右約 463.05，留約 12.95 舞台像素。經典派對哨最右約 812.59，仍在 832 矩形舞台內但超過舊參考安全線，圓角及實際版式須以瀏覽器結果另驗；不能把「矩形未越界」寫成所有空間都安全。
