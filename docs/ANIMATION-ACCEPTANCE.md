# 每批動畫的尺寸與美術驗收

每批新增或改稿，都要完成以下三道檢查。它們不修改 PNG、輪廓或倍率，也不會把候選加入日常或原生資源。

## 直接標記問題畫格（2026-10-12）

可從[健身系列動畫審稿](http://127.0.0.1:8765/preview/?review=candidates&group=fitness&v=20261012-extras1)或[新參考造型](http://127.0.0.1:8765/preview/?review=candidates&group=playful&v=20261012-extras1)選衣服、播一次或逐格看。分類可包含後續批次的新衣服。頁首「這套的大小對照」會帶入目前所選候選與參考造型，不必重新翻整份目錄。同一天的「本批新增」依加入目錄的順序辨識，不用名稱字母排序。

在 [尺寸審稿頁](http://127.0.0.1:8765/size-review/?review=candidates) 的圖片下按「標記這一格」，播放立即停止，編輯區保留當下畫面。可複選大小／比例、裁剪／遮擋、眼睛／配色、動作／接續、服裝／道具，再輸入描述；修改自動保存在本機，亦可按保存。列表可查看、修改或移除單則標記。

候選頁也能按「連播本組」，以正常1×逐套看目前分類；暫停、逐格、換稿／分類、開始寫意見或離頁就中止。它不會批准畫稿，也不會啟動日常事件。[已知待修清單](http://127.0.0.1:8765/size-review/?review=candidates&issues=1&v=20261012-reviewflow1#known-issues)由製作檢查整理，可以篩眼色／動作等問題並直達指定來源格；不自動勾選問題、不寫入使用者意見。原圖SHA不同或來源格不在當前播放版本會拒絕定位，避免把舊問題套到新圖。詳細[檢查結果](../animation/production-20261012-review/README.md)保留覆核範圍和仍未修成處。

「匯出全部意見」的 `patrick-size-review.json` 同時包含原有整段 `notes` 和新增 `frameNotes`。每則逐格意見附來源圖片與輪廓 SHA、候選／日常目錄、版本、播放格和原圖來源格、版式快照、整段倍率、顯示寬度及時間。畫格同時保存零基索引與一基顯示格號，跳格播放不會誤認原圖位置。舊版素材未載入時保留文字，不拿新圖代替。

新逐格資料使用獨立的 `patrick.frame-review.v1` 儲存項，不遷移或清除原有整段意見。多分頁以最新已存資料為基底，刪除的紀錄不從舊分頁復活；尚未成功保存的本頁修改仍可匯出。儲存失敗會顯示提示。程式產生的已知問題顯示在量測報告，不冒充使用者標記。

驗證：`size-review/test-frame-feedback.mjs` 5 項、`size-review/test-frame-feedback-browser.cjs` 6 項通過；包含跳格來源、停播、重載、多分頁刪改、同圖不同版本、容量失敗、候選隔離及 390px 畫面。報告位於 `output/playwright/20261012-frame-feedback/report.json`。這些測試不代表素材美術或真錶驗收通過。

## 1. 先核對量測證據

從本批 catalog 的實際 ID 選取，執行唯讀門檻：

```powershell
node tools/check_animation_acceptance.mjs `
  --audit animation/production-20261007-completion/body-scale-audit.json `
  --clip-ids chef-cookie-repair-20261007,focus-transition-repair-20261007,charging-cozy-20261007 `
  --output output/playwright/20261008-acceptance/evidence.json
```

`--audit` 可以重複；日常資源另加 `--catalog animation/catalog.json`。必須明確提供本批 ID，不能因新稿尚未列入固定清單而漏驗。輸出檔限 `output/`。

門檻實際核對原 PNG、輪廓、原量測來源／landmark 的 SHA，以及每個原始來源格的紀錄；即使播放沒有啟用某格，也不能漏掉。臉寬、两眼下緣間距和真腳底距離必須有對應尺線；未知要保留原因，不准拿透明畫布、帽子、衣服、道具或坐墊外框補值。

- Exit `0`：證據完整；仍需逐格及正常速度的人工審稿。
- Exit `2`：漏格、重複格、過期 SHA、無效尺規或缺少圖稿等，停止宣稱該批已完成尺寸驗收。
- 所有結果保留 `artApproval: false`、`reviewRequired: true`。零個警告也不是美術批准。

整份 catalog 的 SHA 是歷史快照，不以新增其他候選造成的 catalog 變動誤判舊圖過期；採用精確 clip ID、catalog 類別、PNG SHA、輪廓 SHA。顯示尺寸按目前整段固定倍率換算，不能把舊報告預算的舞台大小當作目前畫面。

## 2. 同尺規人工看角色本體

在 `/size-review/?review=candidates&right=<ID>` 看大圖與 200 px 內容舞台、舊稿／新稿、首格／末格及全部四款版式。卡片會明示每段每個人體尺規的可量格數、首末差異，以及全部來源格中哪些仍未知；任何完整性錯誤會停用該段量測數字和尺線，圖稿及既有意見仍可查看。

首末相差或全段最大／最小相差超過 8% 只加一項人工確認提示；8% 不是合格線。原稿既有問題無條件顯示，例如正裝收手末段仍短約 5.19%，不能因低於此值宣稱修妥。表情、轉頭、傾斜、坐姿、側身都會改變可見代理值，不能据此自動縮放。首或末格未知時，差異也必須是未知，不用附近可量格代替。

必看：臉和身體相對其他造型的大小、頭身比例、眼嘴位置、真正腳底與道具支撐的區別；再看時間、日期、資訊欄是否被任何一格遮擋。四款版式使用同一段倍率；不得逐格 fit、縮放或全身擺動掩蓋原畫問題。200 px 是內容舞台寬，並非原生 Watch 全螢幕的等比例承諾。

## 3. 正常 1× 播放與交付

逐格完整可見之後，仍須正常 1× 播一次，確認臉／身體尺寸沒有突然跳變，手、道具和表情過渡合理，末格停住而非偷偷循環。保存所看 clip／PNG／輪廓版本、畫格與版式，以及對應截圖／錄影或實際 draw 時序證據。未能量測的格必須人工看，不能因證據完整就跳過。

交付列出：本批實際來源數／原始格數、每項人體尺規覆蓋、首末未知、固定整段倍率、人工看過的畫格／播放和剩餘缺陷。清楚分開「證據完整」「播放正常」「人物比例仍待修」「使用者批准」。本工具不產生最後一項。

## 要做出來的感覺

主角仍是派大星，有自己的反應、情緒和動作節奏。2D或3D尚未定案；可以認真、呆住、得意、睏倦，也可以好笑。延續不走寫實、令人不適或噁心的方向，不以皮膚孔洞、濕黏質感等細節增加所謂真實感。

主畫面維持**上方清楚的大型電子時間、中央派大星**。電子數字是主要讀時資訊；手臂兼作時／分針，也能暫時離開報時姿勢去演出。少量刻度或12／6可選，不能擠壓數字和角色。其他已確認方向見[角色方向](CHARACTER-DIRECTION.md)。

## 已接受的首段方向與後續擴充

第一段沿用使用者喜歡的星星睡衣角色，演出「**抱枕困倦→擠眼吸氣→抬手遮嘴→大哈欠→放手→抱枕恢復**」。使用者已接受修眼八格的方向，授權按相同邏輯擴充剩餘動作，並要求將眨眼待機與一次哈欠分開。後續可以並行製作，但每組都要獨立通過以下品質檢查；不能把早期「先一段」計畫當成停止擴充的限制。

目前已成功生成一張含**8格2D關鍵畫稿**的原畫集，作為睡前哈欠的粗樣。這是不同姿勢與眼口表情的關鍵影格，仍待補中間幀、穩定角色輪廓，以及重畫自然手臂與報時指針的銜接。即使8格已能按順序播放，也不能稱為完成動畫或已可上錶；本次採2D小樣亦不代表整個專案只採2D。

第一段的角色、自然手臂、眼睛、嘴型與抱枕須依這些關鍵畫稿繼續完善。現有身體PNG加兩片旋轉臂，只能留作舊試玩對照，不能直接換個名稱當作新樣片。第一段在大圖和小尺寸都成立後，再擴充揮手、裝死偷看、生日等其他表演，以及服裝變體。

| 段落 | 畫面必須看得到的變化 | 不足以算這段完成的做法 |
|---|---|---|
| 抱枕困倦 | 抱枕有被手臂托住的接觸，眼皮下垂，身體呈放鬆重心，建立待機姿勢 | 臉完全不變，只在旁邊寫「睏了」 |
| 擠眼吸氣 | 眼皮擠緊，胸腹或頭部有小幅準備動作，嘴從待機轉為吸氣；有短暫蓄勢 | 整張角色等比放大，就當作吸氣；直接跳到最大嘴型 |
| 抬手遮嘴 | 手臂從抱枕旁自然抬起、彎向嘴前；抱枕由另一側合理支撐，手臂與臉的遮擋連續 | 長而硬的手臂片繞胸口掃過；抱枕突然懸空或穿過身體 |
| 大哈欠 | 嘴明確張大，眼皮、臉和身體伸展配合；遮嘴手的位置跟得上，不穿過嘴和眼睛 | 把同一張臉拉大，再加「哈欠」字幕或聲音 |
| 放手 | 哈欠慢慢收住，嘴型縮回，手離開嘴邊落下；眼睛有睜回或眨眼的過渡 | 手突然消失、臉瞬間切回笑容，或只有身體繼續搖 |
| 抱枕恢復 | 手重新接到抱枕，角色重心落穩，眼神恢復困倦／休息，與起始姿勢接得上；後續報時銜接另需讓雙臂回到此刻時間 | 直接閃回首格，抱枕換形或移位；尚未畫出報時銜接就說已能上錶 |

表情不必誇張，但要看得出前後差異。靜音播放、拿掉解說文字後，仍應看懂「睏了→吸氣準備→遮嘴→哈欠→放下手→重新抱枕」。

## 什麼才算真正的角色動作

逐幀繪製，或能讓身體部位實際改變姿勢的分層／變形方式，都可以。驗收看畫面，不以用了多少圖層、幾行程式或取樣次數計分。

| 驗收項目 | 可觀察的通過條件 |
|---|---|
| 姿勢確實不同 | 暫停在吸氣、遮嘴、大哈欠、抱枕恢復等影格時，能指出手臂輪廓、身體重心和頭部朝向的變化；不能把同一張PNG移回原位後就幾乎完全重合 |
| 眼口真的演出 | 眼神／眼皮和嘴型至少隨吸氣、大哈欠、恢復改變；不能只有不動的臉加字幕。眨眼本身也不能代替整段情緒與動作 |
| 手臂像派大星 | 手臂有柔軟、圓厚的海星肢體感，伸出、收回和彎曲時仍接在合理位置；不在胸口露出兩片長而尖硬、像刀的片狀指針 |
| 身體與手臂相連 | 轉動或伸手時，根部、服裝袖口和身體遮擋連續；不出現斷臂、突然多一隻手、穿過臉或道具的情況。內部報時軸不應直接變成胸前的視覺硬件 |
| 動作有原因 | 準備動作發生在伸手前，接觸後道具才受影響，收尾消化前面的動量；快慢和停頓為情節服務，沒有為了顯得在動而全程晃動 |
| 全身變換只作輔助 | 整體位移、旋轉、縮放可用來配合重心，但移除這些效果後，眼口和肢體仍有足夠的表演內容 |
| 道具與表情一致 | 抱枕的形狀、位置與手臂支撐對得上；遮嘴時嘴型與手的遮擋正確；手放下重新抱枕後，不留下穿插或懸空道具 |
| 收尾可接回使用 | 動作結束沒有位置跳變或輪廓閃爍；指針回到當時的時／分，電子數字持續正確更新；再觸發一次也從合理的姿勢開始 |

粒子、光暈、字幕、聲音和震動可以增加趣味，但不能替代以上角色本身的變化。手臂角度改變、整張圖左右擺、或自動化測試通過，都不能單獨證明表演成立。

## 在兩種尺寸與安靜狀態下看

| 檢查方式 | 具體要看什麼 |
|---|---|
| 大圖正常速度 | 看一次完整演出，動作因果清楚、停頓自然；不是幾張姿勢突然互切。可以慢放找問題，但不能只展示慢放版本 |
| 大圖逐幀 | 檢查手臂與身體連接、眼口變化、接觸影格、道具遮擋及收尾；重點部位不融化、閃爍或忽大忽小 |
| 手錶大小預覽 | 額外顯示約200px寬的檢視版本，不靠放大仍能看清主要數字、辨識眼口反應並看懂遮嘴打哈欠；這個縮圖只是檢視尺寸，不能當成真機已測 |
| 上方數字 | 全段保持穩定、清楚且持續更新；帽子、雙臂、蛋糕或其他道具都不能遮住它。時間不跟角色旋轉或縮放 |
| 靜音 | 關閉所有聲音後仍能看懂全段；缺少音效不會失去「吸氣、遮嘴、哈欠、抱枕恢復」等關鍵訊息 |
| 常顯／腕下預覽 | 停止持續演出，留下清楚數字和穩定姿勢；回到可互動狀態後不突然補播過期片段。動畫不能靠常顯全速播放才成立 |
| 減少動態／低電量 | 有簡短、穩定的角色回應或結果畫面；沒有大幅搖晃、反覆彈跳或強閃光，仍知道這次互動的結果 |
| 實機階段 | 使用者型號確定並完成安裝後，再看真實錶面尺寸、抬腕／腕下、常顯亮度、靜音及耗電。瀏覽器預覽不能填成這一項已通過 |

## 第一段要交付的實物

1. 可直接播放的完整小樣：本機頁面、影片或動畫檔，標明版本和正常播放速度。
2. 能核對的實際影格或素材：至少可查看上表六個情節位置。若採分層方式，交付可重播的實際結果及其使用的眼口、肢體素材，不只交一張分層示意圖。
3. 同一段的大圖與小尺寸效果，以及靜音和常顯／腕下的呈現；不能各自換成不同素材掩蓋問題。
4. 簡短記錄哪些項目已實際觀看、哪些仍有穿插／閃爍／讀時問題；真機部分未測就維持未測。

這次8格原畫對應的是上述情節的關鍵姿勢，不能用影格數量取代正常速度的連貫程度。補幀、輪廓穩定與手臂指針重畫未完成前，交付名稱維持「8格關鍵影格粗樣」。

**沒有實際影格或可播放演出，就只能說方案、草圖或素材準備完成，不能說這段動畫做完。**生成失敗、只有單張概念圖，或仍是原圖加位移／旋轉時，要直接保留這個事實。第一段的姿勢、表情、接觸與收尾看得見且經得起小尺寸檢視後，再擴大素材數量。

## 眼部配色必查

使用者指出睡衣眼白被誤畫藍紫。睜眼的眼白需白色、瞳孔黑色；半閉眼及閉眼的眼皮需與角色同為粉色，不能染成睡衣紫。逐格區分眼白與眼皮，八格都需檢視，單張通過不能代表全段通過。

## 2026-10-06 補充：人物本體大小須交叉驗證

相同 PNG 尺寸、透明畫布或完整輪廓高度，不代表裡面的派大星一樣大。帽子、伸手、長哨、坐墊與泡泡都可能改變外框；禁止每格按外框重新縮放來掩蓋原畫體積變化。

1. **共同舞台**：不同衣服在同一個版式、相同顯示寬度、同一參考線下比較。審稿縮圖亦沿用舞台比例，不各自填滿格子；保留校準前後對照。
2. **可見本體**：比對眼睛下緣間距、沿眼線的可見臉部橫截及可確認的眼線至足底距離。它們是姿勢參考，不是解剖測量；閉眼、遮擋、追蹤不可信或只能看到坐墊底時標記未量測。衣服下的軀幹寬不推算。
3. **跨影格與跨造型**：首、中、末格之外仍檢查全來源序列，分清正在播放和被停用的格子。眼口表情和歪頭會改變量測，超差先人工覆核，不能自動扭曲角色使數字相等。
4. **比例與空間一起查**：整段只用一個固定倍率；改後要檢查所有格在四版式中的數字、日期、資訊欄及邊緣。小廚師這種臉偏小但帽子已高的情形，需要原畫比例調整，不能只把整張放大。
5. **獨立覆核**：量測標記直接疊回來源圖，由第二人檢查是否量到手、道具或底墊；另核對網頁與原生公式及實際模擬器容器。200px 網頁檢視不是實體手錶毫米尺寸，也不是實機驗收。
