## 接下來的工作順序

1. **裝置落地**：仍需Apple Watch型號／watchOS、是否有配對iPhone及iOS、或是否家人設定。先完成真機最小閉環：裝上→點按→充電讀值→抬腕／腕下／回時鐘→計時與離線恢復。
2. **選定第一批素材**：使用者逐張確認候選，不把同風格其他圖自動批准。喜歡的概念才進入角色／眼嘴／衣服／道具拆層及動作設計。早期runtime角色仍為草稿。
3. **將驗證過的瀏覽器玩法移植原生**：先充電、晚安、組間休息、日期／節日與餵食；統一情境事件與狀態優先級，保持iPhone／Watch版本相容。現在兩端新玩法尚未完全一致；睡眠時間預設也需統一。
4. **接系統入口**：已存在的Sleep App Intent先接床頭NFC／指定Sleep Focus；新增場景Intent需版本協定、過期事件與離線重送測試。Smart Stack按鈕／watchOS26 Controls依裝置版本開發，不能只改網頁就宣稱已接通。
5. **健身／健康接入**：先用真實Workout／Activity資料做結束慶祝或組間陪伴，再考慮心情紀錄；每種資料有明確用途才申請權限。沒有資料就是未知；手動運動場景不會假裝有運動或心率數據。
6. **擴充內容**：批准後製作短動作包、服裝與節日變體，先在小螢幕驗清楚、回位自然、低電量與腕下不亂動，再擴大數量。
