# 運動資訊版：放大角色與精簡倒數條

2026-10-12，本機修改；沒有提交、推送或 Apple CI。本次修的是版式中人物太小，不是原畫身形或动作接续。

## 改動

原版左側小人物、右側長資訊欄，改成上方大時間、中央人物、底部兩行倒數條。時間仍為120舞台像素，日期仍為40；人物的共同版式倍率由0.56改為0.86，整段線性尺寸增加53.57%。新位移為[58.24,32]；資訊區為[62,818,708,162]，以832×992內容舞台計。

所有造型與所有格使用同一版式倍率。PNG、輪廓遮罩、各 clip.scale、anchor、幀順序與速度均未改。其他三款版式不變。飽足仍可在照顧面板查看；此版只留活動種類、狀態、剩餘時間和進度，避免把人物再次擠小。

Web、尺寸審稿及兩端原生 bundle 使用同一份 `experience/layouts.json`。原生資訊條也改成橫排；Watch 此版的選單按鈕改在右上，省略與底欄重疊的常駐心情短句。摸摸、餵食等既有 `careNotice` 在底欄狀態位置顯示3秒，再恢復倒數狀態；不新增聲音或事件，離頁取消顯示。Web互動短句保留在側面回覆區，不覆蓋此版人物或倒數條。其餘版式的短句和按鈕位置不變。

短訊按每次 `@Published` 發送觸發，初次訂閱不顯示舊值；使用獨立本機revision重新啟動3秒期限，因此冷卻提示相同、親密達上限後訊息相同，仍會重新給回饋。離頁、腕下或離開可互動前景時清除短訊並取消舊期限，不在回來後補顯示。這次補修只影響Watch view，未重跑沒有改動的網頁測試；本機來源檢查仍不能代替Combine/SwiftUI實際編譯及操作。
