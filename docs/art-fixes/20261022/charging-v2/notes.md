## 还没解决的问题（如实）

1. **前倾的表演没了。** 原5–7 是抱着电池往前倾、缩着身子笑，所以显得小；新稿为了守住比例，身体是坐直的，只换了表情。动作的"弹性"比原稿弱，看起来更像一张张表情切换。如果 Sham 更想要前倾的动作，就得以"同尺寸的前倾"重新生成，而不是这样改。
2. **新5 的电池没有像原5 那样倾斜**，眼神也是看向斜上方，不是往下看电池。
3. **新6 的姿势更接近原8，不像原4。** 所以 4→5→6 这一段，身体轮廓会在新5（像原4）和新6（像原8）之间小幅切换（两者 IoU 约 0.91）。原稿本身 4→5 也有同样程度的变化，但这一点要看 GIF 再确认。
4. **新6 的高宽比 −2.7%**，接近 3% 线，但没有超过。
5. GIF 我在工具里看不到动画，只检查了组成它的每一格。
6. 只有 GenerateImage 一种来源，没有多模型对比（工具不支持）。
