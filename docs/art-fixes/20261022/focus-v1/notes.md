# focus-v1 第13–16格 重画候选 · 2026-10-22

## 背景

- 审查报告见 `review/main-atlas-audit-20261022.md`，本项排第 1。
- 原图集 `animation/focus-v1/atlas-generated.png`（SHA 前缀 d1405d87f66a）的第4行（第13–16格）被压扁：
  - 身高比第12格矮约 9%，比现役中位数矮 11%。
  - 高宽比 −7%，不是等比缩小。
- 现役只播 1–12 格。
- 本目录是这 4 格的重画候选。**原图集、catalog.json、App 工程、git 全部没动，也没有推送任何东西。**

## 模型（如实记录）

- 美术像素全部来自内置 **GenerateImage**。
- 它**没有模型选择参数**，每次调用只走一个看不到的后端，无法指定或对比 Grok／GPT 等模型。
- 代码（`build.py`、`anchor_board.py`）只负责以下几件事，没有用代码画任何角色像素：
  - 切格
  - 抠图：只去掉和画布边缘连通的背景，眼白、纸张、衬衫不动
  - 四格统一倍率缩放、脚底中心对齐
  - 对照图、洋葱皮、46mm 预览、预览 GIF、预览图集副本

## 版本

### b1（推荐）：以原第12格为底，只换表情
- 生成方式：GenerateImage 调用 4 次。参考图有两张：
  - 原第12格放大 3 倍，作底：`ref/base-f12-1024.png`
  - 原同号格，作表情参考：`ref/expr-f13…16-1024.png`

  - 新13：得意侧瞄

  - 新15：半垂眼小笑
  - 新16：皱眉专注

## 还没解决的问题（如实）

1. **原图集里放不下。**
   - 新格比原第4行高约 9%，按原位置贴回去，头尖会和第3行的脚重叠 314–432 像素。原第4行当初被压扁，正是因为底边没空间。
   - 真要接入 App，必须重新排版：比如加高画布、加大行距，或者另开一张图集。还要重新生成 `regions-v1.json`、重算 SHA-256、改 catalog 的 frameIndices 和时长。
   - 这些都**没做**，等 Sham 说开 PR 再做。
2. **高清边缘有极淡的浅色描边光晕。**这是 JPEG 带来的，放大 3 倍才看得出来；缩到原图集尺寸和 46mm 上看不见。
3. **第1格比第12格高约 3%**，这是原图集本身的问题，不在本次范围内。如果以后改成循环播放，16→1 会轻微跳大小。
4. **新13的"侧瞄"偏向"斜眼看"。**原第13格是更明显的挑眉侧看，表情张力比原稿弱一点。
5. **预览 GIF 的 13–16 格时长**（300/350/350/700ms）是暂定值。catalog 没有改。
6. **"记事本顶边相对位置"这一项指标比第12格低约 4 个百分点。**但洋葱皮目视记事本是重合的，判断是指标把衬衫袖口一起算了进去，不当作问题。
7. **只有 GenerateImage 一种来源**，没有多模型对比（工具不支持）。
