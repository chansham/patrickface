# 第一批生活情境概念 · 待使用者確認

本輪使用內建 image_gen 工具。充電、健身、睡前三張生成成功，全部是構想候選，不是已批准的畫風、分層動畫或可直接安裝的錶面。節日草稿遭圖片服務的輸出安全檢查攔截，沒有生成成功，也没有冒用其他圖片補位。

| 概念 | 探索方向 | 用途與下一步 |
|---|---|---|
| charging-cel-v1 | 2D、抱電池枕頭補充能量 | App內充電場景，批准後拆角色／枕頭／泡泡與動作 |
| fitness-toon-v1 | 卡通3D、運動頭帶與毛巾 | 組間休息陪伴，批准後做呼吸／擦汗／鼓勵 |
| bedtime-cel-v1 | 2D、睡衣睡帽與枕頭 | 晚安情境，批准後做打哈欠／躺下／醒來 |
| festival-toon-v1（未生成） | 卡通3D、紅衣與燈籠 | 提示已備；本輪服務攔截，造型待補 |

共同要求：主角派大星、完整身體、可愛自然、無寫實噁心插鏡、無毛孔血管等紋理、不把素材生成成功視為使用者批准。2D／3D只是本批不同候選，水墨和抽象仍未排除。

實際生成提示保存在 prompts.json。生成原檔以不重編碼方式複製到本目錄；圖像需先看內容與alpha，再加入審稿列表。
