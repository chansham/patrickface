# 衣櫥與個性探索 · 第二批

用途：讓派大星有嚴肅、疲倦、不耐煩、沉思、發呆、放鬆、懷疑與得意等不同感覺；不把所有造型都做成賣萌。

眼鏡、帽子、正裝、睡衣、睡袍與浴室道具只是候選。使用者喜歡上一批睡衣的星星、帽子與細節，本批繼續嘗試多套不同款式，但沒有因此鎖定全部畫風。

此批使用內建 image_gen；每張提示保存在 prompts.json。每一款都是靜態造型草稿，尚未拆層、綁定或做成可動動畫。圖片是否成功、alpha與來源紀錄見generation-report.json。實際檔案存在才算生成完成。

本批成功5張：嚴肅正裝、疲倦下班、放鬆泡澡、懷疑偵探、得意街頭。薄荷條紋睡衣、深藍月亮睡袍、夏日睡衣共3款遭圖片服務輸出檢查攔截，沒有生成圖檔；保留原提示與待補狀態。連同上一批3張，衣櫥共有8張可檢視圖片。

透明通道已檢查。兩張3D圖仍有彩色光暈；泡澡、街頭圖的少量邊緣像素觸及畫布，正式部件需清理。這些技術問題已記入素材盤點；沒有把概念圖直接宣稱為可換裝的動畫。

泡澡是使用者手動指定的角色場景，不能從這張圖或模擬畫面推導Apple Watch能自動判斷人在泡澡。設備能力與替代觸發見 docs/CAPABILITY-MAP.md。
