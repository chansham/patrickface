## 本機重跑

```powershell
python -B animation/production-20261012-landmarks/measure_review.py --check
python -B animation/production-20261012-landmarks/compare_groups.py
node tools/check_animation_acceptance.mjs --audit animation/production-20261012-landmarks/body-scale-audit.json --clip-ids exercise-repair-20261006,running-first-20261006,charging-cozy-20261007
```

`--check` 只核對現在原稿與已覆核快照。來源或輪廓 SHA 更改會拒絕；版式／目錄更動也會指出投影快照過期，必須先看變更，再使用 `--write` 更新投影。程式不是通用人體辨識器，其眼睛／真腳 ROI 和閉眼／側轉分類只適用於這三份已看過的原畫。
