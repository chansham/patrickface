## 現在可以怎麼看

候選頁增加「連播本組」，按下後將目前分類的可載入畫稿各播放一次，固定正常 1×，段落間停留 350 ms。結束顯示已看組數，不循環、不自動批准。暫停、逐格、點縮圖、換稿、換分類、開始寫意見或離開頁面都会取消連播；日常頁不顯示此操作。

尺寸頁新增可按類型篩選的已知問題。每一格定位先比對原圖 SHA，再由來源格轉換成播放位置；重新編排過的動畫也不會跳錯格。清單只切换比較畫面，使用者自己按「標記這一格」才進入原有意見編輯。來源不同會保留問題文字但停用定位；清單載入失敗不妨礙原有審稿。

可分享指定格連結：`?review=candidates&right=<候選ID>&sourceFrame=<1起算來源格>&sourceSha256=<原PNG SHA>`。缺少版本、版本不符或不在播放序列中的格號會明確拒絕定位，不把它默認成另一格。
