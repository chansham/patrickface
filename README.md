# PatrickFace · 派大星的腕上生活

自用 Apple Watch 角色寵物：上方數字時間為主，搭配真正分格繪製的表情、手勢、衣服與互動。現在可試玩衣櫥、照顧、心情與陪伴計時；新美術仍待逐款確認。它是 Watch App，不是替換整個 watchOS 的主題包。

## 本輪整合（2026-09-27）

- **11 套可選造型、15 種播放編排**已接日常主介面：三款睡衣、原味反應、兩款充電、運動、正裝、派對、泡澡、小廚師。充電新增太空服、頭盔、電池枕和泡泡，原味充電保留。
- 普通／慢／雙眨共用一套 8 張原畫，按不同順序與時間播放；是三種節奏，**不是三套新畫稿**。睡前哈欠與互動各自播放一次，停止後不整張左右晃動。
- 照顧數值與日記保存在本機；手動心情、餵食冷卻、專注／運動陪伴／呼吸倒數有暫停、繼續、取消和一次性完成。取消不發完成獎勵。
- 六個短音效預設靜音；可開啟音效、輕震、情境泡泡／星星／彩紙。12／24 小時、日期、自選服裝、生日／節日與睡眠時段可設定。
- 手臂時計使用新畫的自然手臂及真實时间角度，上方數字獨立；演出結束回到當前時間。手臂接合仍是**待修試稿**，只適用原味時計造型。
- iPhone、Watch 及小工具已進行源碼整合，兩端資源由同一份 catalog／experience 同步。**Windows 檢查不能代替 Apple SDK 編譯；尚無簽名安裝包或真機通過結果。**

## 打開體驗

在資料夾啟動 `python -m http.server 8765 --bind 127.0.0.1`，開啟 `http://127.0.0.1:8765/`。

- [日常主介面](preview/)：換裝、摸頭、餵食、心情、倒數、日記、音效、時計；約 200 CSS px 的小預覽與大預覽同幀。
- [最新偵探試稿](preview/?review=candidates&group=new)：新增帽子、披肩和放大鏡的 12 張原畫。部分眼皮誤畫成紫色、放大鏡大小與過渡待修，僅供審稿，尚未加入日常衣櫥。
- [全部動畫審稿](preview/?review=candidates)：14 組、164 張候選原畫；加原八格哈欠，共 **172 張獨立動畫原畫**。可逐格標記、分開評動作與造型、匯出意見；不會改照顧存檔。太空充電及小廚師舊候選完整保留，主體驗的吃點心仍只播前 11 張。
- [靜態造型衣櫥](wardrobe/)：原有 2D／3D 概念與歷史意見，與主介面的可穿動畫衣櫥分開。被退回舊圖保留對照。
- [全素材盤點](review/)：檔案、版本和歷史審稿。

## 素材品質與缺項

活躍圖集以完整輪廓遮罩取圖，共同畫布、固定落點；不按等距橫豎線切人物，不逐幀拉伸。原 PNG 與來源 SHA 保留。已知有問題的專注 13–16、慶祝 16、泡澡 5、餵食 12 不在日常播放順序中；**這是選格避開問題，不代表原畫已重畫修好**。

本批生成成功 2 組、24 張新原畫；六組服裝／修稿沒有產出。時計另成功一份三層原畫，閉嘴修訂未產出。來源、提示、錯誤與保存位置見 [本批紀錄](animation/production-20260927-batch3/generation-ledger.json)、[時計紀錄](experience/clock/generation.json)、[時計修訂失敗](experience/clock/closed-smile-revision.json)。全部使用內建圖片工具，未切換其他生成管道。

10 月 5 日另新增偵探候選，眼皮修色請求未取得輸出。來源、提示、已知問題及 QC 見 [偵探製作紀錄](animation/production-20261005/generation-ledger.json)。主體驗仍為 11 套造型、15 種播放編排，沒有把待修偵探稿算成已可穿造型。

仍需修動作接續、部分衣紋／體積變化，並補更多季節服裝、夏日睡衣、節慶道具和可組合配件。詳見 [素材缺口](docs/ASSET-BACKLOG.md) 與 [動畫狀態](docs/ANIMATION-STATUS.md)。新稿進開發體驗不等於使用者批准。

## 工程與安裝

- [目前完成程度](docs/PROJECT-STATUS.md)：區分瀏覽器通過、原生源碼、未驗證與未完成。
- [50 項能力地圖](docs/CAPABILITY-MAP.md)：可行性研究，不是 50 項都已實作。充電動畫在 App 內；NFC 由手機自動化轉送；泡澡與心情不假裝自動偵測。
- [私人安裝](docs/INSTALLATION.md)：Windows 開發、macOS 編譯、簽名、配對 iPhone／Watch 驗證。
- [裝置資料](docs/DEVICE-PROFILE-2026-09-27.md)：保留使用者申報，確切型號／系統版本待裝置確認。
- `delivery/theme-pack/` 是舊交付候選，**不是這次動畫和功能版的可安裝包**；`play/` 舊小劇場已退役；Orbit 是另外的實驗。

素材、程式與觀感分開驗證。主動畫、聲音、clock manifest 有驗證器；照顧／計时有純邏輯及瀏覽器測試。原生純邏輯、雙平台編譯與嵌入包檢查入口為 `tools/build_apple_simulators.sh`，只能在 macOS／Apple SDK 執行；無簽名編譯通過也不等於能安裝實機。
